# AWS CloudTrail

AWS CloudTrail is a service that enables governance, compliance, operational auditing, and risk auditing of your AWS account. With CloudTrail, you can log, continuously monitor, and retain account activity related to actions across your AWS infrastructure.

## Key Features
- **API Tracking:** CloudTrail records all API calls made via the AWS Management Console, AWS SDKs, command line tools, and other AWS services.
- **Event History:** Provides a viewable, searchable, downloadable, and immutable record of the past 90 days of account activity.
- **Log Integrity:** You can enable log file validation to determine whether a log file was modified, deleted, or unchanged after CloudTrail delivered it to an S3 bucket.

## Exam Tips
- **Who did what, and when?** Whenever an exam question asks how to audit AWS actions, track API calls, or figure out "who terminated the EC2 instance", the answer is **AWS CloudTrail**.
