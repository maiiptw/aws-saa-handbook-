# Amazon Simple Storage Service (Amazon S3)

Amazon S3 is an object storage service that offers industry-leading scalability, data availability, security, and performance.

## Key Features

- **Storage Classes:** Offers various storage classes designed for different use cases (Standard, Intelligent-Tiering, Standard-IA, One Zone-IA, Glacier).
- **Security:** Supports encryption at rest (SSE-S3, SSE-KMS, SSE-C) and in transit.
- **Data Management:** Lifecycle policies allow you to automatically transition objects between storage classes to save money.
- **Versioning:** Keep multiple variants of an object in the same bucket to protect against accidental deletion.

## Common Use Cases

1. Backup and disaster recovery.
2. Storing assets for web applications (images, videos).
3. Data lakes for big data analytics.

## Exam Tips
- **Standard-IA:** Minimum storage duration is 30 days. There is a retrieval fee. Best for data accessed less than once a month but requires millisecond retrieval.
- **S3 Glacier Flexible Retrieval:** Wait time of 1-5 hours for retrieval. Best for archives.
- **Bucket Policies vs IAM Policies:** Bucket policies apply to the resource (the bucket itself), while IAM policies apply to the user/role trying to access it.
