# Amazon Elastic File System (Amazon EFS)

Amazon EFS เป็นบริการระบบไฟล์ (File System) ที่เรียบง่ายและเป็น Serverless ไม่ต้องตั้งค่าล่วงหน้า ขยายขนาดได้ถึงระดับเพตาไบต์อัตโนมัติโดยไม่กระทบกับแอปพลิเคชัน

## ฟีเจอร์ที่สำคัญ
- **Multi-Instance Access:** EC2 จำนวนร้อยหรือพันเครื่องสามารถเมานท์ (Mount) และอ่าน/เขียนไฟล์ EFS เดียวกันได้พร้อมๆ กัน
- **Elasticity:** ขนาดพื้นที่ยืดหยุ่น หดและขยายอัตโนมัติตามไฟล์ที่มีอยู่จริง จ่ายเงินเท่าที่ใช้
- **โปรโตคอล:** ใช้ NFSv4 (สำหรับ Linux เท่านั้น) หากต้องการแชร์ไฟล์สำหรับ Windows EC2 ต้องไปใช้บริการ Amazon FSx for Windows File Server แทน

## ข้อควรรู้สำหรับสอบ (Exam Tips)
- หากโจทย์ระบุว่าแอปพลิเคชันรันอยู่บน **EC2 หลายเครื่องที่อยู่ต่าง AZ กัน** และจำเป็นต้อง **เข้าถึงไฟล์ร่วมกัน (Shared files)** คำตอบคือ **Amazon EFS**
- ข้อควรจำ: EBS ผูกติดกับ EC2 ได้ทีละ 1 เครื่องเท่านั้น ในขณะที่ EFS แชร์พร้อมกันได้เป็นพันเครื่อง
