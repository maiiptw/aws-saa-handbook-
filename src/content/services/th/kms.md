# AWS Key Management Service (KMS)

AWS KMS เป็นบริการที่ช่วยให้คุณสร้าง ควบคุม และจัดการคีย์การเข้ารหัส (Cryptographic keys) เพื่อปกป้องข้อมูลของคุณ ทำงานร่วมกับบริการ AWS ต่างๆ ได้อย่างแนบเนียน

## ฟีเจอร์ที่สำคัญ
- **Centralized Key Management:** สร้าง ปิดการใช้งาน และหมุนเวียนคีย์หลัก (Master Keys) ได้จากศูนย์กลาง
- **Integration:** เชื่อมต่อกับบริการหลักเช่น EBS, S3, RDS เพื่อตั้งค่าการเข้ารหัสข้อมูลขณะพัก (Encryption at rest) ได้ด้วยการติ๊กเพียงคลิกเดียว
- **Envelope Encryption:** KMS ใช้เทคนิคการเข้ารหัสแบบซ้อนทับ (Envelope) คือ KMS จะไม่ได้เข้ารหัสข้อมูลของคุณตรงๆ แต่จะใช้ Master Key ไปเข้ารหัส "Data Key" อีกที แล้วนำ Data Key ไปเข้ารหัสไฟล์ข้อมูลขนาดใหญ่อีกทีหนึ่ง

## ข้อควรรู้สำหรับสอบ (Exam Tips)
- **CloudHSM vs KMS:** KMS ใช้ฮาร์ดแวร์เก็บคีย์แบบแชร์กัน (Multi-tenant) หากโจทย์ข้อสอบมาจากองค์กรการเงิน/รัฐบาล ที่ต้องการเช่าฮาร์ดแวร์จัดการคีย์เข้ารหัสแบบ **ฮาร์ดแวร์ส่วนตัว (Single-tenant) และผ่านมาตรฐาน FIPS 140-2 Level 3** คำตอบคือต้องใช้ **AWS CloudHSM**
