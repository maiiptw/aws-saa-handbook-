# AWS Lambda

AWS Lambda เป็นบริการประมวลผลแบบ Serverless (ไร้เซิร์ฟเวอร์) ที่ขับเคลื่อนด้วยเหตุการณ์ ซึ่งช่วยให้คุณสามารถรันโค้ดได้โดยไม่ต้องเตรียมการหรือจัดการเซิร์ฟเวอร์ใดๆ คุณจะจ่ายเงินเฉพาะเวลาที่ใช้ในการประมวลผลเท่านั้น

## ฟีเจอร์ที่สำคัญ
- **Serverless:** ไม่ต้องจัดการเซิร์ฟเวอร์ AWS จะดูแลเรื่องโครงสร้างพื้นฐาน การปรับขนาด และความพร้อมใช้งานให้ทั้งหมด
- **Event-Driven:** สามารถถูกทริกเกอร์ (กระตุ้นให้ทำงาน) ได้จากบริการ AWS กว่า 200 ตัว (เช่น มีรูปอัปโหลดเข้า S3, มีข้อมูลอัปเดตใน DynamoDB หรือถูกเรียกผ่าน API Gateway)
- **Concurrency:** ปรับขนาดอัตโนมัติโดยการรันโค้ดคู่ขนานกันตามจำนวนทริกเกอร์ที่เข้ามา

## ข้อควรรู้สำหรับสอบ (Exam Tips)
- **Timeout (เวลาทำงานสูงสุด):** ฟังก์ชัน Lambda หนึ่งตัวทำงานได้นานที่สุด **15 นาที** เท่านั้น
- **Cold Starts:** การเรียกใช้ครั้งแรกอาจมีความหน่วง (Latency) เพราะระบบต้องเตรียมสภาพแวดล้อม หากต้องการแก้ปัญหานี้ให้ใช้ Provisioned Concurrency
