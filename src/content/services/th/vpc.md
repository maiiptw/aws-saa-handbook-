# Amazon Virtual Private Cloud (Amazon VPC)

Amazon VPC ช่วยให้คุณสร้างส่วนเครือข่ายบนคลาวด์ที่แยกตัวออกมาอย่างอิสระ ซึ่งคุณสามารถนำทรัพยากร AWS ต่างๆ มาใส่ไว้ในเครือข่ายเสมือนที่คุณเป็นคนกำหนดเองได้ คุณมีสิทธิ์ควบคุมการตั้งค่าเครือข่ายได้อย่างสมบูรณ์

## องค์ประกอบหลัก

- **Subnets:** ช่วงของ IP address ภายใน VPC (Public subnet ออกเน็ตได้, Private subnet ออกเน็ตไม่ได้โดยตรง)
- **Internet Gateway (IGW):** ช่วยให้ทรัพยากรใน Public subnet สามารถเชื่อมต่อกับอินเทอร์เน็ตได้
- **NAT Gateway:** ช่วยให้ทรัพยากรใน Private subnet สามารถดาวน์โหลด/อัปเดตข้อมูลจากอินเทอร์เน็ตได้ โดยที่คนจากภายนอกไม่สามารถเข้าถึงเข้ามาได้
- **Route Tables:** ตารางกฎที่ใช้ในการกำหนดทิศทางว่าข้อมูลในเครือข่ายจาก Subnet จะต้องวิ่งไปทางไหน
- **Security Groups:** ทำหน้าที่เป็นไฟร์วอลล์เสมือนแบบ Stateful ในระดับอินสแตนซ์ (EC2)
- **Network ACLs:** ทำหน้าที่เป็นไฟร์วอลล์เสมือนแบบ Stateless ในระดับ Subnet

## ข้อควรรู้สำหรับสอบ (Exam Tips)
- **Security Groups vs NACLs:** Security Groups เป็นแบบ Stateful (ถ้าอนุญาตขาเข้า ขาออกจะอนุญาตโดยอัตโนมัติ) ส่วน NACLs เป็นแบบ Stateless (ต้องเขียนกฎอนุญาตทั้งขาเข้าและขาออกแยกกันเสมอ)
- **VPC Peering:** เป็นการเชื่อมต่อ VPC 2 วงเข้าด้วยกันโดยตรง ไม่มีการส่งต่อแบบทอดๆ (Not Transitive) เช่น A เชื่อม B, B เชื่อม C ไม่ได้แปลว่า A จะคุยกับ C ได้
- **VPC Endpoints (PrivateLink):** ใช้ในการเชื่อมต่อจาก VPC ไปยังบริการของ AWS (เช่น S3 หรือ DynamoDB) อย่างปลอดภัยผ่านเครือข่ายภายในของ AWS โดยไม่ต้องวิ่งผ่านอินเทอร์เน็ตสาธารณะเลย
