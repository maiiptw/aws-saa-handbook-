# Amazon DynamoDB

Amazon DynamoDB เป็นฐานข้อมูลแบบ NoSQL (Key-value และ Document) ที่เป็น Serverless และได้รับการจัดการโดย AWS 100% ออกแบบมาเพื่อแอปพลิเคชันที่ต้องการประสิทธิภาพสูงในทุกขนาด

## ฟีเจอร์ที่สำคัญ
- **Performance:** ให้ความหน่วง (Latency) ต่ำระดับตัวเลขหลักเดียวมิลลิวินาที (Single-digit millisecond) อย่างสม่ำเสมอ
- **Serverless:** ไม่ต้องเลือกขนาดเซิร์ฟเวอร์ ระบบปรับขยายขนาดให้อัตโนมัติตามการใช้งาน
- **Capacity Modes:** เลือกได้สองแบบคือ Provisioned (จองโควต้าไว้ล่วงหน้า ราคาถูกกว่า เหมาะกับงานที่คาดเดาได้) หรือ On-Demand (สเกลตามจริงทันที เหมาะกับงานที่เดี๋ยวคนเยอะเดี๋ยวคนน้อย)
- **DynamoDB Streams:** บันทึกทุกการเปลี่ยนแปลงของข้อมูลในตารางตามลำดับเวลา มักใช้จับคู่กับ AWS Lambda เพื่อทำทริกเกอร์อัตโนมัติเมื่อมีข้อมูลใหม่เข้ามา

## ข้อควรรู้สำหรับสอบ (Exam Tips)
- **Global Tables:** หากโจทย์ต้องการฐานข้อมูลข้ามภูมิภาค (Multi-region) ที่สามารถ "อ่านและเขียนได้ทุกฝั่งพร้อมกัน (Active-Active)" คำตอบคือ DynamoDB Global Tables
- **Use cases:** เหมาะมากสำหรับตารางคะแนนเกม, ตะกร้าสินค้า, และเก็บ Session ของผู้ใช้ แต่ **ห้ามใช้** หากแอปพลิเคชันต้องการทำคำสั่ง SQL JOIN ที่ซับซ้อน
