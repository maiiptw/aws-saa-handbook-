# Amazon Kinesis

Amazon Kinesis ช่วยให้การรวบรวม ประมวลผล และวิเคราะห์ข้อมูลที่มีการหลั่งไหลเข้ามาตลอดเวลา (Streaming data) เป็นเรื่องง่าย เพื่อให้คุณสามารถตอบสนองต่อข้อมูลแบบเรียลไทม์

## บริการหลักในกลุ่ม
- **Kinesis Data Streams:** ใช้รับข้อมูลปริมาณมหาศาล (เช่น Logs, ข้อมูลเซ็นเซอร์ IoT, Clickstreams) ข้อมูลที่ส่งเข้ามาจะถูกจัดเก็บไว้ (Retention) ขั้นต่ำ 24 ชั่วโมง ถึง 365 วัน ทำให้แอปพลิเคชันหลายตัวมาไล่อ่านข้อมูลได้
- **Kinesis Data Firehose:** บริการสำหรับส่ง (Load) ข้อมูลสตรีมมิ่งไปยังปลายทางอัตโนมัติ เช่น พ่นข้อมูลลง Amazon S3, Redshift หรือ OpenSearch โดยตรง (ไม่ต้องเขียนโค้ดรับข้อมูลเอง ปรับสเกลให้อัตโนมัติ)
- **Kinesis Data Analytics:** ใช้รันคำสั่ง SQL วิเคราะห์ข้อมูลสตรีมมิ่งแบบเรียลไทม์ได้เลยขณะที่ข้อมูลกำลังวิ่งผ่าน

## ข้อควรรู้สำหรับสอบ (Exam Tips)
- **Kinesis vs SQS:** SQS ใช้เพื่อพักงาน (Decoupling) เมื่อดึงข้อความไปทำเสร็จแล้ว ข้อความจะถูก **ลบทิ้ง** ทันที แต่ Kinesis มีไว้สำหรับข้อมูล Real-time ขนาดใหญ่ ข้อมูลเมื่อถูกอ่านไปแล้วจะ **ไม่ถูกลบ** ทำให้ระบบวิเคราะห์ข้อมูล (Analytics) หลายๆ ตัวสามารถย้อนกลับมาอ่านข้อมูลซ้ำได้
