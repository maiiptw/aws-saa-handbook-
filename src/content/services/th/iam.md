# AWS Identity and Access Management (IAM)

AWS IAM ช่วยให้คุณจัดการการเข้าถึงบริการและทรัพยากรของ AWS ได้อย่างปลอดภัย คุณสามารถสร้างผู้ใช้ (Users), จัดกลุ่ม (Groups) และกำหนดนโยบาย (Policies) เพื่ออนุญาตหรือปฏิเสธการเข้าถึง

## องค์ประกอบหลัก
- **Users (ผู้ใช้):** บุคคล แอพพลิเคชัน หรือระบบ
- **Groups (กลุ่ม):** คอลเล็กชันของ Users การผูก Policy เข้ากับกลุ่มจะทำให้ Users ในกลุ่มได้สิทธิ์นั้นทั้งหมด
- **Roles (บทบาท):** ตัวตนชั่วคราวที่ไม่มีรหัสผ่านถาวร มักใช้กำหนดสิทธิ์ให้กับบริการของ AWS ด้วยกันเอง (เช่น ให้สิทธิ์ EC2 เข้าถึง S3)
- **Policies (นโยบาย):** เอกสาร JSON ที่ระบุชัดเจนว่า อนุญาต (Allow) หรือ ปฏิเสธ (Deny) ให้ทำ Action อะไร กับทรัพยากรไหน

## ข้อควรรู้สำหรับสอบ (Exam Tips)
- **การให้สิทธิ์ EC2:** **ห้าม** นำ Access Keys (รหัสผ่านแบบยาว) ไปฝังไว้ในโค้ดหรือบนเครื่อง EC2 เด็ดขาด วิธีที่ถูกต้องคือการแนบ **IAM Role** ให้กับ EC2 Instance นั้น
- **Least Privilege:** ข้อสอบมักจะเน้นเรื่อง กฎแห่งสิทธิ์ขั้นต่ำ (Principle of least privilege) ให้สิทธิ์เฉพาะเท่าที่จำเป็นต่องานนั้นๆ เท่านั้น ห้ามให้ FullAccess พร่ำเพรื่อ
