# Amazon Relational Database Service (Amazon RDS)

Amazon RDS เป็นบริการฐานข้อมูลแบบจัดการให้ (Managed Service) ที่ช่วยให้คุณติดตั้ง ใช้งาน และปรับขนาดฐานข้อมูลเชิงสัมพันธ์ในคลาวด์ได้อย่างง่ายดาย บริการนี้ช่วยจัดการงานแอดมินที่เสียเวลา เช่น การเตรียมฮาร์ดแวร์ การลงซอฟต์แวร์ อัปเดตแพตช์ และแบ็คอัป

## ฟีเจอร์ที่สำคัญ

- **เอนจินที่รองรับ:** MySQL, PostgreSQL, MariaDB, Oracle, SQL Server และ Amazon Aurora
- **Automated Backups:** เปิดใช้งานการแบ็คอัปอัตโนมัติเป็นค่าเริ่มต้น สามารถเก็บย้อนหลังได้สูงสุด 35 วัน
- **Multi-AZ Deployments:** ให้ความพร้อมใช้งานสูง (High Availability) และรองรับการทำ Failover โดยการจำลองข้อมูลไปยังโหนดสำรอง (Standby) ใน AZ อื่นแบบเรียลไทม์ (Synchronous)
- **Read Replicas:** สร้างโหนดจำลองที่อ่านได้อย่างเดียว เพื่อช่วยแบ่งเบาภาระการอ่าน (Read-heavy) จากโหนดหลัก (ข้อมูลจะถูกจำลองแบบ Asynchronous)

## กรณีการใช้งานทั่วไป (Use Cases)

1. แอปพลิเคชันแบบดั้งเดิม (ERP, CRM, ระบบตะกร้าสินค้า) ที่ต้องการการทำธุรกรรมแบบซับซ้อนและใช้คำสั่ง JOIN
2. ระบบแบ็คเอนด์ของเว็บและแอปพลิเคชันบนมือถือที่ต้องการฐานข้อมูลแบบตาราง

## ข้อควรรู้สำหรับสอบ (Exam Tips)
- **Multi-AZ vs Read Replicas:**
  - **Multi-AZ** มีไว้สำหรับ **High Availability (ทนทานต่อความล้มเหลว)** คุณไม่สามารถรันคำสั่งอ่าน (Read) จากเครื่องสำรองได้
  - **Read Replicas** มีไว้สำหรับ **ขยายประสิทธิภาพการอ่าน (Performance)** คุณสามารถกระจายทราฟฟิกไปให้อ่านได้ แต่ข้อมูลอาจจะช้ากว่าเครื่องหลักเล็กน้อย
- **Amazon Aurora:** เป็นฐานข้อมูลที่ AWS สร้างขึ้นเอง เข้ากันได้กับโค้ด MySQL และ PostgreSQL แต่ทำงานเร็วกว่าสูงสุด 5 เท่า พื้นที่เก็บข้อมูลขยายให้เองอัตโนมัติทีละ 10GB จนถึงสูงสุด 128TB
