# Amazon CloudWatch

Amazon CloudWatch เป็นบริการตรวจสอบ (Monitoring) ที่ช่วยรวบรวมข้อมูลประสิทธิภาพการทำงาน เพื่อให้วิศวกรสามารถดูสถานะของระบบบน AWS ได้แบบเรียลไทม์

## องค์ประกอบหลัก
- **Metrics:** ตัวชี้วัดประสิทธิภาพของทรัพยากร เช่น เปอร์เซ็นต์การใช้ CPU ของ EC2 หรือ จำนวนคิวใน SQS
- **Logs:** ศูนย์รวมล็อกไฟล์ ช่วยให้คุณสามารถเก็บ ค้นหา และวิเคราะห์ล็อกที่ส่งมาจาก EC2, Lambda หรือแอปพลิเคชันของคุณ
- **Alarms:** การตั้งค่าแจ้งเตือน เช่น ถ้า CPU > 80% นาน 5 นาที ให้ส่งอีเมลแจ้งเตือนผ่าน SNS หรือสั่งให้ Auto Scaling Group ขยายเครื่องเพิ่ม
- **EventBridge (ชื่อเดิม CloudWatch Events):** เป็น Event bus ที่คอยจับตาดูเหตุการณ์ที่เกิดขึ้นใน AWS (เช่น สเตตัส EC2 เปลี่ยนจาก Pending เป็น Running) และทริกเกอร์ให้ Lambda ทำงาน

## ข้อควรรู้สำหรับสอบ (Exam Tips)
- **CloudWatch vs CloudTrail:** CloudWatch เน้นเรื่อง **ประสิทธิภาพ (Performance)** (ทรัพยากรทำงานหนักไหม แอปแครชไหม) ในขณะที่ CloudTrail เน้นเรื่อง **การตรวจสอบประวัติ (Auditing)** (ใครล็อกอินเข้ามา? ใครเป็นคนสั่งลบฐานข้อมูลนี้?)
