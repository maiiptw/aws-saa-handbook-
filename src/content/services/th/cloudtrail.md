# AWS CloudTrail

AWS CloudTrail เป็นบริการที่ช่วยในการกำกับดูแล (Governance) การปฏิบัติตามข้อกำหนด และการตรวจสอบความเสี่ยงของบัญชี AWS ของคุณ โดยทำหน้าที่บันทึกประวัติทุกการกระทำที่เกิดขึ้นในระบบ

## ฟีเจอร์ที่สำคัญ
- **API Tracking:** บันทึกประวัติการเรียก API ทุกรูปแบบ ไม่ว่าจะกดผ่านหน้าเว็บ AWS Console, พิมพ์ผ่าน Command Line (CLI) หรือเรียกผ่านโค้ด (SDKs)
- **Event History:** สามารถดู ค้นหา และดาวน์โหลดประวัติเหตุการณ์ย้อนหลังได้ 90 วันฟรี
- **Log Integrity:** สามารถเปิดฟีเจอร์ตรวจเช็คความสมบูรณ์ของไฟล์ล็อกที่ส่งไปเก็บใน S3 เพื่อป้องกันไม่ให้แฮกเกอร์แอบเข้ามาลบหรือแก้ไฟล์ล็อกเพื่อทำลายหลักฐาน

## ข้อควรรู้สำหรับสอบ (Exam Tips)
- **ใคร ทำอะไร ที่ไหน เมื่อไหร่? (Who did what, and when?)** หากโจทย์ข้อสอบถามหาวิธีตรวจสอบ (Audit), ต้องการเช็คประวัติการเรียก API, หรือต้องการหาว่า **"ใครเป็นคนสั่งลบเครื่อง EC2 ตัวนี้?"** คำตอบที่ถูกต้องคือ **AWS CloudTrail** เสมอ
